## Descrição

**Categorias** para organizar os lançamentos e **filtros** para encontrar o que interessa.

## Branch

`feature/06-categorias-filtros`

## Tarefas

- [ ] Categorias padrão: Salário, Alimentação, Moradia, Transporte, Lazer, Saúde, Educação, Outros
- [ ] Permitir ao usuário criar e remover categorias próprias
- [ ] Usar as categorias no `<select>` do formulário de lançamento
- [ ] Filtro por mês/ano (padrão: mês atual)
- [ ] Filtro por tipo (todos, receitas, despesas) e por categoria
- [ ] Busca pela descrição
- [ ] Botão "Limpar filtros"

## Critérios de aceite

- [ ] A tabela de lançamentos responde a todos os filtros combinados
- [ ] Categorias criadas aparecem no formulário de lançamento
- [ ] Não é possível remover uma categoria que tenha lançamentos (ou os lançamentos vão para "Outros")
